# 北邮 810 控制工程基础 · 刷题

北京邮电大学 **810《控制工程基础》** 历年真题刷题网站（2011–2026，共 **16 套 114 题**）。
纯静态页面，不需要服务器，手机/平板/电脑都能用，首次打开后可离线刷题。

## 🔗 在线访问

**<https://alter008.github.io/by810/>**

- iPhone / iPad：Safari 打开 → 分享 → **添加到主屏幕**
- Android：Chrome 打开 → 右上角 ⋮ → **添加到主屏幕**
- 之后就像 App 一样全屏使用，且断网也能继续刷

## ✨ 功能

- 按年份筛选（2011–2026），或「随机一题」
- **看解析**：每题配对应题号的答案解析图，共 74 题（2015–2024、2026）
- **看原卷**：一键调出该题所在的原卷整页，跨页题会显示全部相关页
- 错题本 / 收藏夹 / 标记已掌握（记录在本机浏览器，不上传）
- 每题显示分值、原卷页码；跨页题目自动拼接完整（含图）
- 侧栏带绿色「解」字的题目表示有解析
- 手机端抽屉式目录、点图全屏、左右滑动翻题、自动预取下一题
- 内置 Service Worker 离线缓存，可安装到桌面

## 📝 解析是怎么切出来的

答案 PDF 是扫描件（无文字层），且**各年分题格式都不一样**：

| 年份 | 答案文档里的题号写法 |
|---|---|
| 2015/2016/2017/2020/2021/2022 | `一、【万人教育解析】`（中文数字） |
| 2018/2024 | `1、` 换行 `【万人教育解题】` |
| 2019 | `例一：` `例二：` `例3：` … `例七：` |
| 2023 | 单独一行 `2.` 换行 `【万人教育解析】` |
| 2026 | `【1】【2】…【7】` |

处理流程：逐页 OCR → 剥离粘在题号后的推广语 → 按 5 种格式匹配题号 →
**要求题号从 1 连续到本年题数**（11 套全部通过）→ 以题号为界切成每题解析图。
最终再逐张校验「图内恰好含一个本题题号、且不含其它顶层题号」。
