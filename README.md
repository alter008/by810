# 北邮 810 控制工程基础 · 刷题

北京邮电大学 **810《控制工程基础》** 历年真题刷题网站（2011–2026，共 **16 套 114 题**）。
纯静态页面，不需要服务器，手机/平板/电脑都能用，首次打开后可离线刷题。

## 🔗 在线访问

**<https://alter008.github.io/by810/>**

- iPhone / iPad：Safari 打开 → 分享 → **添加到主屏幕**
- Android：Chrome 打开 → 右上角 ⋮ → **添加到主屏幕**
- 之后就像 App 一样全屏使用，且断网也能继续刷

## ✨ 功能

- 按年份筛选（2011–2026），或「随机一题」
- 错题本 / 收藏夹 / 标记已掌握（记录在本机浏览器，不上传）
- **看原卷**：一键调出该题所在的原卷整页，跨页题会显示全部相关页
- 每题显示分值、原卷页码；跨页题目自动拼接完整（含图）
- 手机端抽屉式目录、点图全屏、左右滑动翻题、自动预取下一题
- 内置 Service Worker 离线缓存，可安装到桌面

## 📁 目录结构

```
index.html            页面入口
style.css / app.js    样式与逻辑
data.js               题库索引（题号、分值、图路径、原卷页码）
pages.js              原卷页映射
sw.js / manifest.webmanifest / icon-*.png    PWA（离线 + 添加到主屏）
assets/q/<年份>/<题号>.jpg     切好的题图，共 114 张
assets/pages/<年份>/<页号>.jpg 原卷整页，共 48 张（"看原卷"用）
```

## 💻 本地使用

```bash
# 方式一：直接打开
# 双击 index.html 即可（不需要任何依赖）

# 方式二：起个本地服务（推荐，Service Worker 才能生效）
python -m http.server 8080
# 然后浏览器打开 http://localhost:8080
```

## 🚀 部署

本仓库使用 **GitHub Pages**：Settings → Pages → Source 选 `main` 分支 `/ (root)`。
推送 `main` 后 1–3 分钟自动发布。

## 📖 数据说明

题图全部由**原卷扫描件**按题号精确切分而来，未做任何内容改写，仅切分与拼接。
每道题的切图范围依据题号行定位，并经过「题号连续性 + 分值合计 = 150 分 + 逐题图内题号校验」
三重自动核对。
